本版新增系统分享，补全 Skill 的编辑与导入流程，无破坏性改动。

## 系统分享

- 在文件管理、相册或浏览器中将文本、图片与文件分享到 Mingent，主页进入分享模式：上方为当前会话，下方为待发内容与目标键。
- 目标键用于选择工作区与会话，也可在当前工作区新建会话；选定即切换，发送前可确认去向。
- 支持一次分享多个文件与多张图片；文件在发送时复制进目标工作区，重名自动追加序号。
- 图片按统一规则处理：总像素不超过 2048×2048，单张不超过 4MB；带透明通道的转为 WebP，其余转为 JPEG，并按拍摄方向校正；尺寸与体积在限制内的静态 PNG、WebP 原样保留。
- 图片与普通文件的单张上限均为 50MB。
- 长文本转为附件保存，面板中补写的正文一并保留。

## 对话界面

- 复制按钮改为常显图标，位置与宽度固定，不随触摸出现或收起，右侧内容不再随之位移。
- 附件按文本、代码、表格、PDF、文档、压缩包、图片等九类显示图标。
- 进入主页时定位在最后一条消息：冷启动、从后台返回、生成回复中与空会话均如此，不再出现底部留白。
- 会话标题在首条消息后由模型生成，上限 80 字节；手动修改过的标题不会被覆盖。

## Skill

- 在「设置 → 包管理 → Skill」中点按任意一行，可编辑名称、描述、适用场景与正文；正文框兼作预览。
- 名称、描述、正文均为必填。描述是助手判断何时使用该技能的唯一依据，缺少时在列表中高亮提示。
- 导入同名技能前先确认覆盖；编辑导入的技能时，许可证、允许工具等元数据原样保留。
- 描述中的适用场景一并进入助手可见的技能目录，便于判断何时加载。
- 新增 `skill_save` 能力：仅在明确要求记录或固化时，将一套做法保存为本地技能，与手动创建的技能完全一致。
- 包管理页的标签页顺序调整为 Skill 在前、插件（MCP 服务）在后。

## 定时任务

- 回复中的「当前时间」按任务实际触发时刻生成，不再沿用上一轮的日期。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载会一并清除。
- 从 1.3.2 升级无需重新填写 API Key。
