本版修正用量统计的计费口径，并将浏览、预览、计划三页的顶栏合并为一行。

## 用量统计

- 联网检索计入用量：检索消耗的 token 与调用次数一并计入会话累计与总账。
- 价目改为官方人民币峰谷价：工作日 09:00–12:00、14:00–18:00 为高峰，其余时段与周末按半价计。
- 检索按每千次 5 元单独计费，不并入上下文构成。
- 会话标题请求同样计入用量。
- 上下文洞察的请求图浮层新增「检索 API 次数」，与「请求次数」并列显示。
- 浮层文字不再被右侧边缘截断。

## 页面顶部

- 浏览、预览、计划三页的顶栏合并为一行，返回、标签与页面动作同排，正文获得更多显示高度。
- 选中标签的文字即页面标题，不再另起一行书写页面名称。
- 标签按数量分配宽度，数量较多时左右滑动。
- 文件预览页右滑不再唤出侧边抽屉，与浏览、计划两页一致。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载将同时清除这些数据。
- 历史用量的 token 与次数不变，费用按新价目折算。
