本版不含新增功能，只修正定时任务的一处上下文问题。

## 修复的问题

1.3.0 在把历史交给定时任务之前，会删掉「与本轮指令逐字相同」的历次投递，连同紧随其后的答复。这项处理的本意是防止模型复述上一轮答复，代价是周期任务看不到自己上一轮做了什么：需要「与昨日相比」「本周累计」这类延续信息时，任务手里没有材料。

同时，1.3.0 按固定条数截取历史。每轮截出的起点不同，请求前缀随之变化，服务端的前缀缓存无法复用。

本版改为与普通对话同一口径：目标会话的历史整段携带，不做删减。长度由既有的上下文压缩处理，工具调用的配对由发送前的清洗处理。

## 验证

- 建一个每分钟执行的任务，指令为「第一次回 1，此后每次回上一次数字加 1」。实测答复依次为 1 至 7，说明每轮都读到了上一轮的答复。
- 日志记录「历史携带」条数逐轮增长（66 → 68 → …），确认完整携带而非截断。
- 后台各轮的缓存命中率为 98.3%–98.6%，与「不移动窗口」的预期一致。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载会一并清除。
- 与 1.3.0 之间无需重新填写 API Key。
