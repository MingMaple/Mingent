本版优化图片查看与页面阅读的动效和返回路径，减少阅读时的视线与操作中断。

## 图片查看

- 打开图片时，背景的虚化与暗化自零点起随图片放大同步加深，图片完全展开时达到最深。
- 关闭图片时，背景虚化随图片缩回同步淡化，图片回到缩略图位置后彻底消失。
- 下滑关闭图片的过程中，背景虚化同样随下拉幅度实时变淡，不再出现背景先变或后变的脱节。
- 虚化随动画逐帧变化，图片缩放保持流畅。

## 页面顶部

- 浏览页与文档预览页的顶部控制栏按一次完整的滑动判定显隐，与常用手机浏览器一致：向上滑动收起，向下滑动展开。
- 小幅滑动不改变顶栏状态，翻页阅读时不会一阵一阵地闪。
- 文档预览页在控制栏收起时，轻触页面即可唤出控制栏。
- 计划页的顶部控制栏保持常驻，不受本项影响。

## 返回路径

- 预览页内由正文链接逐层打开的文件，系统返回先逐层退回上一层预览，回到第一层后再返回主页。
- 从预览页打开网页后，从浏览页返回会回到离开时的预览页，阅读位置保持不变；从主页打开的网页仍返回主页。
- 同一网页标签内进入多层页面时，系统返回逐层退回该标签的历史页面，退到最初网页后再返回上一级页面。

## 预览页点击

- 屏幕中央轻触只用于唤出顶部控制栏，不触发其他功能。
- PDF 与 DOCX 保持只读，文档内链接不会把页面带出预览。
- Markdown 文档中的链接仍可打开：产物文件在预览页内新建标签，普通网址进入内置浏览页。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载将同时清除这些数据。
