本版相对上一次发布（1.2.6）：91 个既有文件改动、16 个新增文件；改动部分新增 1,924 行、删除 641 行。

## 关于本版

1.2.6 及以前，助手写入的文件保存在工作区目录中，查看时需另行打开文件管理器。本版新增产物预览：回复末尾列出本轮写出的文件，正文中出现的工作区路径可以点击打开，进入预览页；预览页右上角提供导出入口，可交给设备上其他应用打开。助手也可以调用新增的 `present` 工具，把终端命令生成的文件一并交付。

使用上有三点变化：

- 写入结果在对话内即可确认，不必切换到文件管理器。
- Markdown、代码、纯文本、PDF、图片与 docx 可以在应用内阅读，阅读后再决定是否导出。
- 导出后由设备上已安装的应用继续处理。

本版修复了两个问题：定时任务「新闻」在两天的执行中均未产生可用答复；对话进行中追加的消息未能送达模型执行。前者影响定时任务在无人值守时能否使用，后者影响长任务进行中调整指令是否可靠。

## 新增：产物预览

- 助手写出的文件在回复末尾以卡片列出，默认显示 3 条，其余条目展开后显示；正文中的文件路径可以点击打开。
- 预览页按标签管理已打开的文件，可切换、可关闭；关闭最后一条后返回主页。标签清单按会话保存，进程被回收后再次进入时依然存在。
- 支持的格式：Markdown、代码、纯文本、PDF、图片、docx。
- 导出入口固定在预览页右上角，各格式位置一致。
- 新增工具 `present`：把终端命令或其他方式生成的文件交付到卡片与预览；`write_file` 写出的文件自动显示在卡片中。

## 对话体验

- 运行中按过程组折叠：思考与工具调用按分组收为一行摘要，并给出各类调用的计数；正文照常显示，最后一组保持展开。
- 插话发送：运行期间追加的消息立即出现在对话中，不打断当前步骤，模型完成当前步骤后可读取并执行。
- 被插话截断的上一轮立即折叠为一行计数，不再平铺展示多个工具卡片。
- 后台任务结算通知不再显示为用户气泡，改为在回合上方显示一行触发说明。

## 定时任务

- 工具轮数上限由 8 提高至 48；无人值守执行到达上限时追加一次请求，强制产出正文，不再以报错代替回复。
- 历史中略去同一任务的历次投递，避免模型重复上一轮答复。
- 定时结果曾写入空白会话，导致有通知而会话中无内容；现已改为写入前将目标会话转为正式会话，读取时再补充一次判断。
- 编辑已有任务时可以重新绑定会话，不再只能查看。
- 备份纳入定时任务清单，恢复或换机后任务不再整批丢失。

## 安全

- 对整个仓库执行代码审查（279 个文件），修复 80 个文件中的问题，包括技能导入的路径穿越、备份解压缺少大小上限、软链接删除越界、终端文件提供方的路径逃逸、SSH 服务空口令启动、日志中的明文口令、无法停止的动画循环。
- 通知跳转改为一次性令牌：其他应用无法通过启动参数指定会话，伪造或重放的令牌只返回默认界面。
- 子智能体不再发送系统通知，结果返回父会话与面板，需要时可在子智能体页查看。

## 界面

- 新增预览页：顶栏固定，文件信息位于正文顶部；切换标签时正文交叉淡化，各标签保留自身滚动位置。计划页采用同一套过渡。
- 表格与代码区右侧加入渐隐提示，用于提示内容可横向滑动。
- 长文本的「加载更多」移入正文末尾，滚动至已读内容末尾时才显示。

## 修复

- 定时任务「新闻」第一天无任何答复，第二天重复上一份答复；本版已修复。
- 运行期间点击队列行的「插话发送」无反应；本版已修复。
- 长文本预览页的「加载更多」始终显示；本版已移入正文末尾。
- 切换标签时顶栏、说明与正文同时整体替换，观感突兀；本版改为正文交叉淡化。

## 已知限制

- 内置终端与记忆内核仅支持 arm64 设备。APK 为通用包，其他架构可以安装，但仅有界面与网络类功能可用。
- targetSdk 固定为 28（PRoot 的硬性依赖）；定时任务的实际触发比计划晚 19–33 秒，周期本身不漂移。
- 应用内预览有体积上限：docx 8 MB、图片 24 MB、PDF 40 MB，超过时提示用其他应用打开。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载会一并清除。
- 1.2.x 与 1.3.0 之间升级无需重新填写 API Key。
