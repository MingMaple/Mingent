本版相对上一次发布（1.1.2），累计 91 次提交、242 个文件变更（新增 31,613 行、删除 18,463 行）。

## 架构：六层模块化落地

- 代码按 app / feature / capability / core / infra / uikit 六层重组，全部位于 :app 模块；:terminal 只保留随仓库 vendored 的 Operit 终端核心。
- 新增构建期分层断言 :app:checkArchitecture，越界即构建失败；跨层白名单已清零。
- MCP 调用、终端桥与模型提供方全部收敛到 infra，业务层不再直接接触上游接口。

## 新增：洞察页

- 单页替代原上下文页：用量、费用、性能三张卡片，配合全局统计与会话联动。
- 总账 v2：按天、按构成、按缓存、按耗时六段计时，自带 v1 数据迁移。
- DeepSeek 费用引擎：区分峰谷时段计价，费用口径可按提供商扩展。
- 分叉会话继承基线，统计只从分支起点算起。

## 新增：后台任务

- 新增 job_start / job_output / job_list / job_kill 四个工具，任务在后台执行并实时增量输出，可真正中断。
- 任务结束发结算通知；繁忙时注入、空闲时唤醒，与定时任务共用执行通道。

## 安全

- 模型 API Key 改用 AndroidKeyStore + AES-256-GCM 加密存储；旧的明文 Key 清空重置。
- 删除操作维持「工作区外与通配删除一次一码授权 + 默认进回收站 + 关键目录永久拒绝」两级链路，全过程写审计日志。

## Agent 内核与提示词

- 技能按需加载补齐触发规则与结果信封，不再全量注入。
- 提示词补搜索时的思考过程、人设收敛与时间感知三项能力。
- 长会话压缩的摘要模型可选用任意已配置的提供商。

## 界面

- 配色系统 v4 全量落地；深色聊天气泡分档，用户气泡改为 #2F3237。
- 竖屏固定按状态栏高度留白，回到前台时顶栏不再跳动。
- 冷启动直接落到会话底部，消除先显顶部再闪跳的现象。
- 计划页与浏览页统一圆角按压；浏览页顶栏的刷新与分享改版。
- 长消息按轮次折叠，更早内容按整块截断并渐隐压边，可展开与收起。

## 性能

- 会话表读盘移入 IO 线程，图片改为采样解码，启动与页面 IO 移出主线程。
- 定时任务在后台的触发可靠性提升。

## 修复

- 修「思考 / 工具执行中」过程区被折叠后又自行展开。
- 修后台任务连续唤醒上限，任务结束后未归还独占执行通道。
- 修终端环境配置重复打开实例、输入行透明穿帮。
- 修工具执行期间误判回合结束。
- 若干文案、排版与坐标细节修正。

## 已知限制

- 内置终端与记忆内核仅支持 arm64 设备。APK 为通用包，其他架构可以安装，但仅有界面与网络类功能可用。
- targetSdk 固定为 28（PRoot 的硬性依赖）；定时任务的实际触发比计划晚 19–33 秒，周期本身不漂移。

## 升级说明

- 覆盖安装即可，数据保留；跨版本升级请勿卸载，卸载会连同会话、密钥与终端根文件系统一并清除。
- 从 1.1.2 及更早版本升级时，因密钥存储方式更换，需在「设置 → 模型」重新填写 API Key；1.2.x 之间升级不受影响。
