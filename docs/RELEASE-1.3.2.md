本版继续完善用量统计、定时任务与对话界面，无破坏性改动。

## 用量统计

- 「近 7 天 / 近 30 天 / 全部」的折线改为可交互：点按或拖动曲线查看某一时段，浮层随手指横向移动，显示该时段的合计，以及「命中缓存 / 未命中缓存 / 输出」三项明细；点按图表以外的区域收起浮层。
- 浮层宽度按该图最宽的一条内容适配，同一张图内保持恒定；Token 与请求两种口径各自计算宽度。
- 纵轴上限按数据自动取整并标出上限值；全为 0 时不画上限。
- 「今天」改为 0 时至 24 时的分时折线，只画到当前小时，末端圆点即「现在」；点按同样给出该时段的数值浮层。
- 修复「近 7 天 / 近 30 天」把历史遗留用量摊入第一格所导致的假尖峰，曲线与区间总量口径一致。
- 修复首次启动回填用量后，「今天」各小时之和与当天累计不一致。

## 上下文配置

- 修复「保留上限」输入框把左侧标签与右侧预算文字挤成一字一行的问题。
- 摘要与压缩事件改为「描述一行 + 时间一行」显示，长描述不再被挤断。
- 「留空或填 0 表示不设上限」的文案与实际提交行为一致。

## 定时任务

- 后台请求按会话摘要裁剪：会话经过上下文压缩的任务，不再把已摘要掉的原文整段重发。
- 指令输入框改为固定高度，内容较多时在框内滚动，不再把整页顶长。

## 对话界面

- 气泡下方的时间按日期分档：当天只显示时刻；同年更早显示「月日 + 时刻」；跨年再补年份。页面停留跨过零点时，标签自动更新。

## 升级说明

- 覆盖安装即可，会话、密钥、终端环境与记忆数据均保留；请勿卸载，卸载会一并清除。
- 与 1.3.1 之间无需重新填写 API Key。
