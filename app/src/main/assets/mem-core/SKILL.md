# 记忆内核库 · 记忆内核

## 是什么

一个**通用记忆内核**：把对话、经历、偏好、知识与技能，变成**可检索、会衰减、能巩固、可重建**的长期记忆。

- **记忆的物理形态**：`_Data/events/*.jsonl` —— **append-only（只追加）** 的事件流，是唯一真相源；所谓「遗忘」只体现为检索强度下降与归档，**事件永不删除**。
- **检索**：BM25（SQLite FTS5）+ 向量（可选）+ 图扩散 → RRF 融合 → 重排 → **截断 3~5 条**。
- **输出**：检索返回**结构化简报（briefing）** —— 主题 / 时间线 / 现状 / 相关实体 / 情绪与偏好线索 / 来源 id，**不是片段列表**。
- **「学习」模块（同工作区的兄弟库，属库外模块）是这个内核的第一个使用者**；内核本身与场景无关（聊天、诉苦、其他项目同样适用）。

**不负责**：代替用户完成作业与考试；也不替用户判断隐私边界（披露等级为 `public` / `ask` / `private`）。

## 何时挂载

见上方 frontmatter 的 `description`。归纳为四类：

| 用户意图 | 例子 |
|---|---|
| 写入记忆 | 「记住这个」「把这条记下来」 |
| 回忆检索 | 「你还记得…吗」「回忆一下」「上次那个…」 |
| 维护巩固 | 「更新记忆」「巩固一下」「清理记忆」 |
| 跨会话延续 | 新会话继续旧话题、需要历史上下文 |
